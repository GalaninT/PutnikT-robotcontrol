# PutnikT-robotcontrol
Control algorithms for a mobile robot with wheel-legged chassis
Synthesis and simulation of control algorithms for a mobile robot with four wheel-legged chassis in MATLAB/Simulink and MSC Adams.
# PutnikT — Control System for Wheel-Legged Mobile Robot

Дипломная работа бакалавра: синтез алгоритмов управления мобильным роботом
с колёсно-шагающим шасси. Проект выполнен в СПбПУ (Высшая школа автоматизации
и робототехники) на базе ЦНИИ РТК.

## О проекте

Робот представляет собой четырёхногую платформу, на конце каждой ноги
закреплено колесо. Каждая нога имеет 4 степени свободы: бедренный, коленный,
рулевой и колёсный шарниры. Реализована модульная система управления на
основе типовых операций, объединяемых в сложные сценарии.

**Основные возможности:**
- Управление в колёсном режиме (движение по прямой и дуге)
- Управление положением колеса в декартовых координатах
- Пошарнирное управление отдельными сочленениями
- Сложные сценарии: перешагивание, поворот на месте, движение по траектории
- Co-simulation с MSC Adams для расчёта контактных взаимодействий
